# 입력 품질이 인간 행동에 의존하는 파이프라인은 기술 우회보다 입력 표준화가 먼저 병목이 될 수 있다

## Statement
입력 품질이 인간 자세나 행동에 크게 의존하는 문제를 기술 우회안으로만 풀려고 하면, 실제 병목인 입력 표준화 문제가 가려질 수 있다.

## Description
XR 캡처 및 센서 입력 파이프라인에서는 기술 스택보다 인간 입력 표준화가 핵심 병목일 수 있다.
