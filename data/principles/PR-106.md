# 역할 부여보다 질문 프레임 전환이 더 중요할 수 있다

## Statement
언어모델에게 전문가 역할을 부여하는 것보다, 사용자가 구조와 관측과 표준 절차를 묻는 질문을 하는 편이 디버깅 품질을 더 크게 바꿀 수 있다.

## Description
프롬프트 역할 설정보다 질문 내용과 구조가 더 중요할 수 있다.
