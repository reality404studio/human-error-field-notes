# 모델이 다음 액션을 자동 제안할수록 사용자는 현재 목적과 단계 위치를 명시적으로 재고정해야 한다

## Statement
모델이 강하게 다음 단계를 제안하는 대화에서는, 사용자가 현재 작업의 위치와 목적을 주기적으로 재고정해야 한다.

## Description
다음 단계 제안 관성은 협업을 빠르게 만들기도 하지만 원래 목적을 흐리게 할 수 있다.
