# 초기 구조 혼합으로 생긴 기술 부채는 나중에 UX 부채로 변환되어 나타날 수 있다

## Statement
초기 구조 혼합으로 생긴 기술 부채는 나중에 UX 부채로 변환되어 나타날 수 있다.

## Description
아키텍처 부채는 나중에 사용자 경험 비용으로 재청구된다.
