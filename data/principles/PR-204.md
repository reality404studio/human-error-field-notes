# 이해하지 못한 장문 절차를 그대로 수행하는 방식은 구현 성공률이 낮다

## Statement
사용자가 이해하지 못한 절차를 길게 수행하는 방식은 구현 성공률이 낮다.

## Description
절차량이 늘어날수록 의미 해석이 더 중요해진다.
