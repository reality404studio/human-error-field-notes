# 목적함수 명확화만으로는 제약 식별을 대체할 수 없다

## Statement
목적함수를 명확히 주는 것은 해결책 생성에는 유리하지만, 숨은 제약 식별이 빠진 상태에서는 잘못된 구현 루프로 사용자를 밀어 넣을 수 있다.

## Description
목표 명확화는 중요하지만 제약 명세 누락 시 위험하다.
