# 구조를 모를 때는 고쳐줘보다 원리가 뭐냐를 먼저 물어야 한다

## Statement
시스템 모델이 없는 상태에서는 왜 안 됨보다 원리가 무엇이고 구조가 어떻게 되어 있나를 먼저 물어야 한다.

## Description
구조 질문은 디버깅 이전의 모델 획득 단계다.
