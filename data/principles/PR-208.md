# 전체적으로는 실패해도 일부 하위 시스템은 동시에 안정화될 수 있으므로 결과를 단일 실패로 뭉뚱그리지 말아야 한다

## Statement

## Description
mixed outcome을 분리 기록해야 실제 학습이 남는다.
