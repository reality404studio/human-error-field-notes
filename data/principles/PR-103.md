# 다른 방법 요구는 프레임 전환을 보장하지 않는다

## Statement
다른 방법을 요구하는 것만으로는 문제 프레임이 바뀌지 않으며, 오히려 더 위험한 저수준 설정 변경으로 이어질 수 있다.

## Description
조치의 다양성과 문제 프레임의 전환은 다르다.
