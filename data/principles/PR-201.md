# 인간이 이해하기 좋은 개발 플랜은 모델이 바로 실행하기 좋은 작업 단위와 다를 수 있다

## Statement
인간이 이해하기 좋은 개발 플랜은 모델이 바로 실행하기 좋은 작업 단위와 다를 수 있다.

## Description
인간 설명용 계획을 모델 실행 계획으로 착각하면 출력이 비대해질 수 있다.
