# state-and-feature-coupled-too-early (PAT-202)

**Type:** failure

## Definition
상태 설계와 기능 구현을 너무 이른 단계에 함께 묶어 진행하는 패턴

## Agent Response
상태 정의를 먼저 분리하고 기능 구현은 그다음에 하도록 재구성한다.
